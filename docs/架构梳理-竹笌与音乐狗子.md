- **创作台**：对话流（用户输入 + 预设 prompt 气泡）、消息展示、自动滚动到底、情绪识别（`_detectUserMood`：难过 / 开心 / 激动 → sad / happy / excited）
- **歌词创作**：`createLyrics(theme, style, mood, additional, userMood)`，歌词预览卡（`_LyricsPreview`）
- **音乐生成**：`generateMusic(lyrics, prompt, duration, language)`，生成中动画、底部音乐播放器（`_MusicPlayer`，播放 / 进度 / 时长）
- **歌词库**：3 首内置 demo（标题 / 风格 / 情绪 / 预览歌词），播放 / 编辑 / 分享占位按钮
- **宠物页**：`ChattyDogPet`（6 情绪 × 7 动作）
- 启动时 `_tryFlush()` 补发离线发件箱

### 狗子形象 `chatty_dog_pet.dart`
- `PetMood{happy, excited, sleepy, hungry, confused, angry}`

### 后端接口（`PET_API_URL` dart-define，默认 `http://localhost:8000`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/pet/state/{userId}` | 宠物状态 |
| POST | `/pet/interact/{userId}?action=` | 宠物互动 |
| POST | `/chat` | AI 对话（含 lyrics_intent / music_intent / pet_state） |
| POST | `/lyrics` | 歌词创作 |

### 数据模型（`pet_api_service.dart`）

### 离线优先
`LocalChatRepository`（`zhuyapp_chat.db`，表 `chat_history` + `outbox`），乐观写库 → `markSynced` / `markError` → `flushOutbox()` 联网补发（遇首个失败即停，保留剩余发件箱）

## B7. 原生层配置

**Android / iOS**：该分支**未提交任何原生层目录**（无 `android/`、`ios/`），因此无包名、权限、SDK 版本配置可梳理——平台层由各自 `flutter create` 时生成，未纳入该分支版本控制。

**运行期需要的原生能力**（从依赖反推的能力映射，非清单文件）：

| 依赖 | 需要的原生能力 |
|---|---|
| `audioplayers` | 网络音频播放（Android 需 `INTERNET`；HTTP 明文需 `usesCleartextTraffic`） |
| `sqflite` / `path_provider` | 本地数据库与文件目录 |
| `http` | 网络访问 |

无麦克风 / 相机 / 蓝牙 / 权限插件依赖，因此该版本**不含 ASR、拍照、LiveKit 通话**。

后端地址注入方式：编译期 `--dart-define=PET_API_URL=...`，默认 `http://localhost:8000`（安卓模拟器实机调试通常改为 `http://10.0.2.2:8000` 或局域网地址）。
