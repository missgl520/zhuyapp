## 三、安装 Git

**作用：** 版本控制，克隆和推送代码

**下载地址：** <https://git-scm.com/download/win>

**安装选项（一路下一步即可，注意以下几点）：**

- ✅ 勾选 **Git Bash Here**（右键菜单出现 Git Bash）
- ✅ 勾选 **Use Nano as default editor**（或选 VS Code）
- ✅ 勾选 **Git from the command line and also from 3rd-party software**
- ✅ 勾选 **Enable symbolic links**（可选，提交代码需要）

**验证：**

```bash
git --version
# 输出类似：git version 2.44.0.windows.1
```

## 四、安装 Flutter SDK

**版本要求：** 3.44.6（必须精确匹配）

### 4.1 下载

打开浏览器访问：

```
https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.44.6_stable.zip
```

### 4.2 解压安装

1. 创建安装目录（**不要用中文路径！不要放 C:\Program Files！**）

```bash
# 推荐解压到 C:\flutter
# 右键 flutter_windows_3.44.6_stable.zip → "全部解压缩" → 选择 C:\
```

1. 解压完成后目录结构：

```
C:\flutter\
  bin\
    flutter.bat    ← 重要
  ...
```

### 4.3 配置环境变量

**步骤：**

1. 按 `Win + R`，输入 `sysdm.cpl`，回车
2. 点击 **高级** → **环境变量**
3. 在 **系统变量** 里找到 `Path`，双击编辑
4. 点击 **新建**，添加：
   ```
   C:\flutter\bin
   ```
5. 点击确定，一路确定退出

### 4.4 验证 Flutter 安装

打开 **PowerShell** 或 **Git Bash**，输入：

```bash
flutter --version
# 输出：Flutter 3.44.6 • channel stable • https://github.com/flutter/flutter.git
```

如果报错"无法识别 flutter"，**关掉终端重新打开**再试。

## 五、安装 Android Studio + Android SDK

Flutter 需要 Android SDK 才能打包 APK。

### 5.1 下载 Android Studio

下载地址：<https://developer.android.com/studio>

### 5.2 安装过程

1. 运行安装程序，一路 Next
2. ✅ 勾选 **Android Virtual Device**（模拟器）
3. 安装路径建议：`C:\AndroidStudio`
4. 安装完成后启动，首次会弹出 Setup Wizard

### 5.3 Setup Wizard 配置

1. **Install Type**：选 Custom
2. **Select JDK Location**：自动检测到就好
3. **SDK Components**：
   - ✅ Android SDK
   - ✅ Android SDK Platform（选 Android 34）
   - ✅ Performance（Intel HAXM）或 ARM
   - ✅ Default Installation Folder 改为：`C:\AndroidSDK`

### 5.4 配置 Flutter 使用 Android SDK

打开 PowerShell：

```bash
# 告诉 Flutter Android SDK 在哪
flutter config --android-sdk C:\AndroidSDK

# 查看配置结果
flutter doctor
```

### 5.5 同意 Android 协议

```bash
flutter doctor --android-licenses
```

一路输入 `y` 同意所有协议。

### 7.1 安装依赖

## 八、配置后端（Python）

### 8.1 安装 Python

**下载地址：** <https://www.python.org/downloads/>

**版本：** Python 3.10 ~ 3.12（推荐 3.11）

**安装注意：**

1. 运行安装程序
2. ✅ 勾选 **Add Python to PATH**（重要！）
3. ✅ 勾选 **Install pip**（一般默认勾）
4. 点击 **Install Now**

**验证：**

```bash
python --version
# 输出：Python 3.11.8  或类似
```

### 8.2 安装后端依赖

```bash
cd C:\zhuyu-project\zhuyapp-backend

# 创建虚拟环境（推荐）
python -m venv venv

# 激活虚拟环境
# Windows PowerShell：
.\venv\Scripts\Activate.ps1
# 或 Git Bash：
source venv/Scripts/activate

# 安装依赖
pip install -r requirements.txt
```

> `requirements.txt` 内容：
>
> - fastapi==0.128.0
> - uvicorn[standard]==0.51.0
> - httpx==0.28.1
> - sse-starlette==2.3.0
> - pydantic==2.10.6
> - psutil==6.1.1

### 8.3 配置环境变量

在后端目录下新建文件 `.env`：

```bash
cd C:\zhuyu-project\zhuyapp-backend

# 创建 .env 文件
# Windows PowerShell：
New-Item -Name ".env" -ItemType File

# 然后用记事本打开编辑：
notepad .env
```

填入以下内容：

```env
# Agnes API Key（必须）
# 获取地址：https://apihub.agnes-ai.cn → API Keys → Create
AGNES_API_KEY=你的 Agnes API Key

# Agnes Base URL（一般不改）
AGNES_BASE_URL=https://api.agnes-ai.cn/v1
AGNES_MODEL=agnes-2.0-flash

# 记忆后端（开发用 simple，生产用 sinomem）
MEMORY_BACKEND=simple

# 启动人格（gentle / playful / wise）
ACTIVE_PERSONA=gentle

# Cartesia TTS（可选）
CARTESIA_API_KEY=

# MiniMax TTS（可选，中文情感音色）
MINIMAX_API_KEY=
MINIMAX_VOICE_TYPE=female-tnewscn
```

### 8.4 启动后端

```bash
# 确保虚拟环境已激活
.\venv\Scripts\Activate.ps1

# 启动后端（端口 8000）
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

看到以下输出说明启动成功：

```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete.
```

## 九、运行竹芽 App（开发模式）

### 9.1 连接手机真机（推荐）

1. 手机开启 **开发者选项** → **USB 调试**
2. 用数据线连接电脑
3. 手机上点击"允许 USB 调试"
4. 查看设备：

```bash
adb devices
# 输出：List of devices attached
#        xxxxxx device
```

1. 运行：

```bash
cd C:\zhuyu-project\zhuyapp
flutter run
```

### 9.2 连接模拟器

1. 打开 Android Studio → Device Manager → 创建虚拟设备（Pixel 6，Android 34）
2. 启动模拟器
3. 运行：

```bash
flutter run -d emulator-xxxx
```

### 9.3 修改后端地址（如果手机无法连接）

Flutter 默认连接 `http://10.0.2.2:8000`（Android 模拟器专用），真机需要改成本机 IP：

编辑 `lib/core/config/app_config.dart`：

```dart
static const String baseUrl = 'http://你电脑的局域网IP:8000';
```

获取本机 IP：

```bash
ipconfig
# 找 IPv4 地址，如：192.168.1.100
```

## 十、打包 APK（本地构建）

### 10.1 Debug APK

```bash
cd C:\zhuyu-project\zhuyapp

# 构建 Debug 版本（约 5-10 分钟）
flutter build apk --debug

# 产物位置：
# build/app/outputs/flutter-apk/app-debug.apk
```

### 10.2 Release APK（需要签名）

```bash
# 首先生成签名密钥（只需做一次）
keytool -genkey -v -keystore zhuyapp.jks -keyalg RSA -keysize 2048 -validity 10000 -alias zhuyapp

# 然后构建 Release
flutter build apk --release
```

### 10.3 安装到手机

```bash
# 用数据线连接手机后
adb install -r build/app/outputs/flutter-apk/app-debug.apk

# 或者直接把 APK 文件传到手机微信/文件管理里打开安装
```

## 十一、常见问题排查

### Q1: `flutter: command not found`

环境变量没配好。关掉终端，重新打开 PowerShell，输入 `flutter --version` 验证。

### Q2: `Android SDK not found`

```bash
flutter config --android-sdk C:\AndroidSDK
flutter doctor --android-licenses
```

### Q3: `pip: command not found`

Python 安装时没勾选 Add to PATH。重新运行 Python 安装程序，勾上那个选项。

### Q4: 后端启动报错 `Module not found`

虚拟环境没激活。进入虚拟环境后再运行：

```bash
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Q5: 手机装不上 APK（解析错误）

手机需要开启"允许安装未知来源应用"：设置 → 安全 → 未知来源应用 → 允许。

### Q6: Gradle 下载慢 / 失败

Flutter 国内镜像。创建/编辑 `C:\Users\你的用户名\.gradle\init.gradle`：

```groovy
allprojects {
    repositories {
        maven { url 'https://maven.aliyun.com/repository/google' }
        maven { url 'https://maven.aliyun.com/repository/public' }
    }
}
```
